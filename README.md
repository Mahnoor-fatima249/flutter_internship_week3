# Flutter Internship Week 3

## CRUD Operations & Local Data

### Objective
Learn CRUD operations using local data with Provider state management.

### Tasks Completed
- Created a To-Do App
- Add a Task
- Edit a Task
- Delete a Task
- Mark a Task as Completed
- Display tasks using ListView.builder
- State management using Provider (instead of setState)

### Topics Covered
- Dart List
- ListView.builder
- setState() then changed to Provider
- CRUD Operations
- ChangeNotifier & Consumer
